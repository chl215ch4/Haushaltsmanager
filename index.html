☁️ Google Sheets Cloud Sync (Live-Safe)

Verbinde deine Haushalts-Datenbank mit einer kostenlosen Google Tabelle. Jede Änderung wird automatisch live gespeichert und beim Start synchronisiert.

📖 Wichtig: Google Script Vorlage & Berechtigungen

Damit der Abruf ohne "Failed to fetch" funktioniert, muss die Web-App für „Jeder“ freigegeben sein und sowohl JSON als auch JSONP unterstützen.

  1. Öffne deine Google Tabelle → Erweiterungen → Apps Script
  2. Ersetze den gesamten Code durch folgendes Skript: 
    function doGet(e){
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  var val = sheet.getRange(1, 1).getValue();
  var cb = e && e.parameter ? e.parameter.callback : null;
  if (cb) {
    return ContentService.createTextOutput(cb + '(' + JSON.stringify(val || '{}') + ')')
      .setMimeType(ContentService.MimeType.JAVASCRIPT);
  }
  return ContentService.createTextOutput(val || '{}')
    .setMimeType(ContentService.MimeType.JSON);
}

function doPost(e){
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  var data = e && e.postData ? e.postData.contents : '';
  if (data) {
    sheet.getRange(1, 1).setValue(data);
  }
  return ContentService.createTextOutput('{"status":"ok"}')
    .setMimeType(ContentService.MimeType.JSON);
}
  3. Klicke auf Bereitstellen → Neue Bereitstellung
  4. Typ: Web-App auswählen
  5. Ausführen als: Ich (deine E-Mail)
  6. Wer hat Zugriff: Jeder (auch anonym) ⚠️ (Extrem wichtig gegen "Failed to fetch"!)
  7. Kopiere die Web-App-URL (sie endet auf /exec) und füge sie oben ein!
